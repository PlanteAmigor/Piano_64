# 蓝牙收谱与 SD 保存

BT36 的 TX 接 FPGA AB20（BT_RX），RX 接 AA21（BT_TX），共地、3.3 V UART。默认 115200 baud、8N1。U15 仍为原有调试串口。

沿用工作区 `ref/bt36_v3/fpga_bt_v3/PROTOCOL_V3.md` 的 v3 帧和 Android App。App 必须等 ACK 再发下一帧。QUERY 如实报告本版容量 **2048 个事件**；不要按参考工程的 8192 硬编码发送。

## 操作

1. 保持原有 FAT32 卡中的 P64.BIN 和 SONG 文件。上电等音源加载、歌曲目录完成。
2. 手机连接 BT36，发送 BEGIN、连续 DATA、END。界面显示接收、保存、成功或失败。
3. END 成功后，曲谱已成为根目录一个新的 `SONGxx.BIN`，并完成逐扇区读回核对和歌曲目录刷新。不会自动播放。
4. 手机 PLAY 从 SD 重新加载刚保存的曲谱，进入现有播放页；STOP 或页面上的停止键释放声音。也可随后在歌曲列表选择它，以自动或教学模式演奏。
5. 重新上电后，已保存文件仍可通过歌曲列表播放；手机 QUERY 的“已提交”指本次开机的上传会话，复位后需重新上传才能用手机 PLAY。

按第一个未使用的编号从 SONG01..99 分配，已有曲谱不覆盖。目录容量仍为 16 首。若卡内已有 SONG01..05，新曲通常为 SONG06。已有编号有空缺时先填空缺。

## 协议补充

ACK 仍是 type=80、14 字节 payload、原请求 seq、CCITT-FALSE CRC。成功重复请求按 type/seq/CRC 识别，仅重发确认；重复 END 不会再次存卡，重复 PLAY 不重新触发。CRC 错误可重传原帧。DATA 内容、偏移、排序、音域、时长、力度或容量错误会终止本轮上传，需要重新 BEGIN。

END 的成功 ACK 延迟至保存和目录刷新结束，受手机 5 秒 ACK 预算约束。保存失败返回通用状态 3，界面另有存储错误码。不会将未完成保存的曲谱声明为已提交。BEGIN 停止正在播放的曲谱；PLAY 在纯音测试模式返回状态 6。QUERY 返回实际播放状态和位置。

flags bit0 延续原协议的超声部丢音选项；bit7 为本工程已有的混合乐器扩展。bit7=0 时完全兼容统一音色 App。bit7=1 时，每个事件的音高最高位与力度最高位携带 2 位乐器号，时长最高位标识伴奏，实际时长为 15 位。并发容量为 7 个钢琴/古筝声部和 1 个唢呐/笛子共享管乐声部；混合曲谱超容量会被拒绝。参考 `tools/gen_song_multi.py`。

存储错误：20 文件系统不支持或损坏；21 目录遍历超限；22 歌曲数量/编号已满；23 空间不足；24 SD 读写失败；25 写后读回不一致；26 操作超时；27 保存后的目录刷新失败。错误后可重新 BEGIN。

## 存储实现与范围

采用现有 SD 原生 1-bit 接口，新增 CMD24 写扇区、数据 CRC16、响应 token、busy 等待及 CMD13 状态检查。音色读取器与写入器独占使用 SD，低电平交接 SD 时钟。保存不会重新写入 DDR 音色镜像。

支持 FAT32、512 字节扇区、每簇 1..128 个扇区（2 的幂）、1/2 个 FAT、镜像或指定活动 FAT，及无分区表或 MBR 第一分区为 0B/0C 的卡。仅追加根目录 8.3 文件名；FAT16、exFAT、GPT 和其他 MBR 分区位置不在写入范围内。

流程为扫描目录/空闲簇、写并验证文件内容、更新并验证 FAT/FSInfo，最后写并验证目录项。所有已有文件簇均不复用。该实现没有文件系统日志：写 FAT 或目录期间断电/拔卡，可能留下孤立簇或不一致的 FAT 副本；它不提供断电原子性。超时和硬件写入错误返回失败，不盲目重试元数据。保存时保持卡插入并供电。

## 复验

`python3 tools/check_bt_store.py`：真实 UART 帧与 ACK、CRC/超时/重传、存储失败、混合事件、完整 SD CMD/DAT 卡模型、FAT 存盘、目录刷新、既有播放器，以及独立 Python 磁盘解析验证。FAT 测试覆盖 2048 事件、碎片空间、多簇大小、镜像/活动 FAT、MBR、目录扩展、无空间/满目录/几何错误和故障注入。

`python3 tools/check_all.py`：原有音频、教学、曲谱加载和显示回归。`python3 tools/render_ui1080.py --jobs 9`：实际显示 RTL 的像素输出。`./build_full.sh`：完整构建并检查全局 setup/hold，无违例才可交付烧录。

电脑当前没有挂载工程 SD 卡。仿真磁盘均位于 work/，不会写电脑其他磁盘；真实手机、SD 卡、显示和声音的联调需要板上验收。
