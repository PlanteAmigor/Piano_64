# 720p 先行与 1080p 优化

先交付 1280×720 60Hz 完整功能固件，之后独立优化 1920×1080 60Hz。蓝牙 v3 收谱、SD 自动存储与目录刷新、多乐器自动演奏、教学兜底、三页界面和音频修复在两个目标中共用。

720p 使用 CEA-861 时序：74.25 MHz 像素时钟、371.25 MHz 串行时钟，1650×750 总周期。两级 PLL 参考 27.5 MHz、视频 VCO 742.5 MHz，不通过降低刷新率规避时序。逻辑界面坐标仍为 1920×1080，以 3:2 采样输出，页面无裁剪。

切换：`python3 tools/set_video_mode.py 720p` 或 `python3 tools/set_video_mode.py 1080p`。工具同时修改 RTL 模式头文件和像素/串行时钟约束，随后必须 `./build_full.sh` 完整构建。烧录前 `./flash.sh --check` 核对源码、固件及全局 setup/hold 均通过。

本轮共用优化：播放器和预览合并为同一块真双口事件 RAM；FAT 扇区缓存合并为单写口；文件长度计算分级寄存；SD 校验计数按字节并行计算进借位。这些改动保持文件格式和播放行为不变。

720p 烧录后，1080p 实验在独立源码快照进行，板上保持已验证的 720p 固件；只有新的完整时序通过后才替换。
