# 1080p 页面与多乐器主旋律教学

## 使用

- KEY0 在主页面、纯音测试、教学页面之间切换。
- 主页面保留实时频谱、64 分量与李萨如，显示当前音色、效果、手势和力度。
- 测试页面保留八键纯音测试，增加八个实体键的按住状态。
- 教学页面：R1[8] 下一首；R2[8] 确认。模式页用 R1[8] 切换自动演奏／教学，R2[8] 开始。演奏时 R2[8] 停止；长按 R2[8] 返回。
- 教学准备 3 秒。前七个琴键固定对应 C/D/E/F/G/A/B（Do/Re/Mi/Fa/Sol/La/Si），八度与乐器由曲谱自动指定；第八条“*”是自动黑键提示，不要求按键。
- 音符下落至金色判定线时按对应键。长条表示持续时间。钢琴青色、古筝金色、唢呐粉色、笛子绿色；暗色音符是自动伴奏；命中显示亮绿。
- 节拍点主旋律未匹配时以半力度准时发声，±150 ms 内按对后平滑恢复正常力度，不重新起音。按错不额外出声。伴奏始终正常演奏，不计入漏按或期待琴键。
- 光学力度和技法只作用于教学主旋律；伴奏不受影响。笛子继续使用原有音色自带气颤。
- 新示范曲 `SONG05.BIN` 是多乐器《小星星》：主旋律依次使用笛子、古筝、唢呐、钢琴，钢琴低音与古筝分解音自动伴奏。将其复制到装有原 P64.BIN 的 SD 卡根目录；不必替换原四首曲谱。歌曲顺序以实际 SD 目录为准。

## 显示

原生 1920×1080，60 Hz，像素时钟 148.5 MHz。2200×1125 总时序，水平前肩88、同步44、后肩148，垂直前肩4、同步5、后肩36，正极性同步。

50 MHz 先经参考 PLL 生成27.5 MHz（VCO1100 MHz，PFD50 MHz）；视频 PLL 以27.5 MHz为输入，VCO742.5 MHz，生成148.5 MHz像素时钟与742.5 MHz串行时钟。两个PLL均按器件允许范围配置；约束描述真实频率。

字库为原生16×32，标题按整数倍显示。李萨如保留256×256坐标、2位强度与四档余辉，在512×512窗口整数放大；与旧128×128/4位接口兼容。频谱、字形、图形与颜色分级流水；坐标先寄存，再经过九级像素流水，输出同步信号延迟与像素数据一致。显示用滤波与AGC在音频全局50 MHz域运行，完成坐标经翻转信号同步发布到像素域。

曲谱预览有独立同步读取口，每次扫描发布最多32个可见音符，不占用播放器读取周期。预备拍可提前看到音符；每5 ms移动1像素，可看约3秒后续曲谱。状态和音符描述通过握手跨时钟域整体传递。

## 多乐器曲谱扩展

继续使用v3帧及8字节事件。原SONG01～04及所有flags bit7=0的文件保持原格式、音色与声部容量。

BEGIN.flags bit7=1启用扩展：

| 原字段 | 扩展含义 |
| --- | --- |
| start_ms u32 | 开始时间，不变 |
| note低7位 | MIDI音高 |
| note bit7、velocity bit7 | 合并成2位音色：`{note[7],velocity[7]}` |
| duration低15位 | 时长1～32767 ms |
| duration bit15 | 0主旋律，1自动伴奏 |
| velocity低7位 | 力度1～127 |

音色编码0钢琴、1古筝、2唢呐、3笛子。混合曲谱同时支持7个钢琴／古筝声部，以及1个共享的唢呐／笛子声部。两种管乐可以先后切换，但不能同时重叠；超容量、非法音域、零时长、错误CRC及保留标志位均拒绝加载。混合格式即使设置旧allow_drop也不允许丢音。

生成示范曲：`python3 tools/gen_song_multi.py`。可导入此工具的`encode(events)`生成自己的曲谱，事件为`(开始ms, MIDI音高, 时长ms, 力度, 音色, 是否主旋律)`。该工具验证音域、时长和并发容量，不是通用MIDI文件播放器。

## 时序优化

- 文字候选并行寄存后合并；背景几何判断与颜色选择分开，避免穿过所有琴键、曲目卡片和图层的串行判断链。
- TMDS用256×18位同步字节查找表完成跳变最小化，并预计算两种差分增量；后级以半单位维护4位有符号运行差分，反馈路径仅保留选择与一次4位加法。32768个连续符号逐个对比独立DVI算法。
- 音频软限幅分为五个短时钟阶段，保留原24000膝点及32192最大幅值；遍历全部16位输入的×2／×8／×16结果与原公式完全一致。
- DDR命令、写数据分别缓冲，读数据与有效信号一起寄存，保留独立握手；SD完整读写回校验覆盖随机等待。
- 上电复位比较先寄存；FAT长文件名的13字符组偏移先计算，避免字节到文件名寄存器路径中的乘法。

## 复验

- `python3 tools/check_all.py`：原功能回归、多乐器加载／教学、真实P64参数DMA、真实曲谱预览、I2S混响与吹奏持续发声，以及李萨如坐标／亮度存储。
- `python3 tools/check_all.py --ui`：另捕获三个页面及选择、准备、错误、空曲库、播放中的实际RTL画面。
- `./build_full.sh`：完整构建并校验源文件指纹、资源和全局setup／hold结果；不接受过期或时序失败固件。
- `./flash.sh --check`：确认工程与可烧录固件匹配。

板上试听与显示验收：确认显示器报告1080p60；先测试原有琴键、混响和长按笛子，再选择SONG05教学。无需手动切换音色或八度；漏按仍听到主旋律，按对后主旋律变强，伴奏保持连续。
