# 系统总览（总计）

日期：2026-10-31
平台：Gowin **GW5AST-LV138PG484AC1/I0**（Tang Mega 138K Dock）

**一句话：一块 FPGA 上跑 4 种乐器（钢琴 / 古筝 / 唢呐 / 笛子），
8 键 + 移调，1040 音参数全部放 DDR3，上电由 SD 卡灌入。**

---

## 1. 资源与时序（当前版本）

| 项目 | 占用 | 比例 |
|---|---:|---:|
| Logic | 20510 / 138240 | 15% |
| Register | 16926 / 139095 | 13% |
| BSRAM | 202 / 340 | **60%** |
| DSP | 89.5 / 298 | 31% |
| **时序** | **0 条违例** | 最差 **+0.006 ns**（SETUP，SD FAT 解析器 `u_ld/u_f`，老路径） |

> ⚠️ 最差 slack 只有 +0.006 ns，非常薄。**每次改动后必须看 `impl/pnr/piano64.timing_paths`
> 的第一条**；SD FAT 解析那段是随机布线的产物，换个 seed 就可能翻负。

## 2. 四种乐器

| # | 乐器 | 灯色 | 引擎 | 音域（MIDI） | 音数 | 8 键音阶 | 移调 |
|---|---|---|---|---|---|---|---|
| 0 | 钢琴 | 白 | `add_engine8`（128 分量模态） | 21–108 | 88 | C4 七声 | −36 … +36 |
| 1 | 古筝 | 青 | `add_engine8`（同上，换表） | 38–86 | 49 | D4 **五声**（键 4、7 屏蔽） | −24 … +12 |
| 2 | 唢呐 | 橙 | `add_engine_harm`（谐波） | 69–96 | 28 | A4 七声 | 0 … +12 |
| 3 | 笛子 | 紫 | `add_engine_harm`（**共用实例**） | 67–91 | 25 | **G4 七声** | 0 … +12 |

### 8 键音阶明细

```
钢琴  C4(60) D4(62) E4(64) F4(65) G4(67) A4(69) B4(71) C5(72)
古筝  D4(62) E4(64) F#4(66) --   A4(69) B4(71) --    D5(74)
唢呐  A4(69) B4(71) C#5(73) D5(74) E5(76) F#5(78) G#5(80) A5(81)
笛子  G4(67) A4(69) B4(71) C5(72) D5(74) E5(76) F#5(78) G5(79)
```

> 笛子 8 键里有 **7 个是实测锚点**，只有 **72(C5)** 是移调补的
> （G 大调的第 4 级，绕不过去）。其余 12 个半音是移调补点，误差听不出来。

### 操作

| 动作 | 效果 |
|---|---|
| 按键 1–8 | 发音（力度靠击键速度，前 7 键松开即停） |
| **长按第 9 键 1 s** | 切换音色：白 → 青 → 橙 → 紫 → 白 |
| **第 10 键**（移调） | 轻击 = +12，重击 = −12；到边界停住不循环；切音色清零 |

## 3. DDR3 镜像布局（`P64.BIN`）

| 段 | word 范围 | 大小 | 说明 |
|---|---|---|---|
| 文件头 | — | 32 B | magic `P64I` / version / total_words / checksum / 各段基址 |
| 钢琴 | 1 … 5632 | 176 KiB | 88 音 × 64 word（128 分量按分量交错） |
| 古筝 | 5633 … 8768 | 98 KiB | 49 音 × 64 word |
| 唢呐 | 8769 … 22175 | **419.0 KiB** | 28 音，段头 + 描述符 + 8 段表 |
| 笛子 | 22176 … 35248 | **408.5 KiB** | 25 音，同上 |

```
total    35249 word = 1127968 B = 1101.5 KiB
checksum 0x789BA11D
加载器上限 MAX_BYTES = 1,280,000（余 152 KB）
```

### 上电串口输出（正常）

```
P64 v8 C=1 L=1 P=1 R=1 S=00
LD BY=00113620 W=000089B1 R=000089B1 HT=000089B1 D0=01FA902E D1=00DDD8F5 CK=789BA11D OK=1
```

| 字段 | 含义 | 当前值 |
|---|---|---|
| `BY` | 文件字节数 | `0x113620` = 1,127,968 |
| `HT` | 总 word 数 | `0x89B1` = 35,249 |
| `CK` | 校验和 | `0x789BA11D` |
| `OK` | 校验通过 | 1 |

> ★ **改过镜像就必须换 SD 卡**。`HT`/`CK` 对不上就是旧卡——
> 曾经因为旧卡导致「钢琴音高音色全乱 + 古筝没声」，排查了很久。

## 4. 时钟与音频

```
CLOCK_50 → PLL → clk_sys 50 MHz
fs = 50 MHz ÷ 16 ÷ 64 = 48828.125 Hz   （I2S → PCM5102A）
每样点 1024 拍（引擎的流水调度窗口）
DDR 用户域 clk_x1 = 100 MHz
```

- **为什么 48828.125**：必须是 50 MHz 的整数分频，且每样点留够流水拍数。
  48828.125 与 48000 只差 1.7%，听不出来，但换来整齐的分频。
- **为什么每样点 1024 拍**：4 声部 × 最坏 K=62 谐波 = 248 拍，加前置/排空 ≈ 278 拍，
  1024 留了 3.7 倍余量给模态引擎和取表。

## 5. 模块清单

### 顶层

| 文件 | 作用 |
|---|---|
| `src/add_top.v` | 键盘、音色切换、移调、三引擎、DDR 三路仲裁、输出增益、软限幅 |
| `src/key_dual.v` | 双触点按键，算击键速度（力度） |
| `src/note_alloc.v` | 8 键 → 8 声部轮转分配；`note_base` / `key_step` / `key_enable` / `transpose` 都是端口（每乐器不同映射） |
| `src/sd_ddr_loader.v` | 上电从 SD 读 `P64.BIN` 灌进 DDR3，串口打 `LD` 报告 |
| `src/ddr_wrap.v` | DDR3 控制器封装（**不要把 `src/ddr/ddr3_1v4_hs.cst` 加进 build.tcl**） |

### 模态引擎（钢琴 / 古筝）

`add_engine8.v` → `add_voice8.v`（128 分量，8 级流水）+ `param_cache.v` + `ddr_param_dma.v`

按音从 DDR 取 64 word 进 BSRAM 缓存。详见 `doc/发声原理与算法.md`。

### 谐波引擎（唢呐 / 笛子，**单实例共用**）

`add_engine_harm.v`（4 声部流水，1 谐波/拍）+ `harm_buf.v` + `suona_dma.v`

按音从 DDR 取 8 段表（最大 24.5 KiB）进 BSRAM，约 200 µs。

**共用机制**——切音色只改 4 个运行时输入：

| 端口 | 唢呐 | 笛子 |
|---|---|---|
| `note_lo` / `note_hi` | 69 / 96 | 67 / 91 |
| `inf_base`（info 表字偏移） | 0 | **112** |
| `desc_base`（描述符 app 地址，已扣 `note_lo×16`） | `((8769+2)<<3) − 69×16` | `((22176+2)<<3) − 67×16` |

> 这样比"两个引擎实例"省了约 **50 块 BSRAM**，也省一条 DDR 仲裁。
> 代价是切音色时正在响的音会被停掉——但切音色本来就会清移调，听感上无差别。

### 外设

`pcm5102a_tx.v`（I2S）、`ws2812_keyind.v`（灯带 / 音色灯）、`mix_sum.v`（混音 + 二次肩软限幅）

## 6. 输出定标（关键，别乱动）

```
引擎输出 → mix_l_r / mix_r_r（打一拍）
        → sat_gain(mix, timbre)      ← 每种乐器不同增益
        → out_l_r / out_r_r（再打一拍，切断到 u_tx 的长路径）
        → pcm5102a_tx
```

`sat_gain` 的增益：

| 音色 | 增益 | 引擎峰值 | 乘完 | 判定 |
|---|---|---:|---:|---|
| 钢琴 | ×8 | ~817 | 6536 | 直通 |
| 古筝 | ×16 | ~324 | 5184 | 直通 |
| 唢呐 | ×2 | 7943 | 15886 | 直通（膝点 24000） |
| 笛子 | ×2 | 7943 | 15886 | 直通 |

软限幅：膝点 24000，`y = 24000 + d − d²/32768`，`d` 钳在 16384 → 最大 32192，永不削顶。

> ★★ **引擎输出峰值必须≈满刻度的 1.0 倍**（对应 `mix` 峰值 ≈ 8192）。
> 高了会进软限幅被压成近方波（听感「嘟嘟」+ 更响更糊），低了浪费动态范围。

## 7. 加新乐器（第 5 种）的检查清单

按顺序做，一步都不能省：

1. **拟合**：`tools/<inst>_batch.py` → `out/<inst>/谐波/harm_*.npz`
2. **打包 hex**：`tools/npz2hex_harm2.py --norm`
   > ⚠️ **`--norm` 必须开！** 它按模型重建信号的峰值逐音归一化。
   > 不开的话某个音可能峰值到 3.2，×2 后顶进软限幅（笛子就是这么翻车的）。
3. **拷 hex 到工程根**：`<inst>_ab.hex … <inst>_info.hex`（只需 `_info.hex` 会被 `$readmemh`）
4. **`tools/make_ddr_image.py`**：加一段，抄 `pack_suona(...)`
5. **`src/harm_buf.v`**：`m_inf` 再扩 100~112 词，加一行 `$readmemh("<inst>_info.hex", m_inf, base, base+n-1)`
6. **`src/add_top.v`**：
   - `timbre_r` 位宽够不够（4 档刚好 2 位，5 档要 3 位）
   - `is_gz` / `is_harm` 之类的判据**全部写 `==` 比较**，不要用位切片
   - `t_note_base` / `t_key_step` / `t_key_en` / `tr_min` / `tr_max`
   - `harm_note_lo/hi`、`harm_inf_base`、`harm_desc`
   - `sat_gain` 加一档
   - DDR 仲裁
7. **`src/ws2812_keyind.v`**：加一种颜色
8. **检查每音表是否塞得进 BSRAM 缓冲**：`AB_DEPTH=64 / ENV_DEPTH=8192 / PSI_DEPTH=4096 / PHI_DEPTH=1024`
   （对应 K ≤ 62、(npsi+1)×151 ≤ 4096、K×76 ≤ 8192）
9. **检查镜像 < `MAX_BYTES`（1,280,000）**，不够就抬参数
10. **换 SD 卡**，核对串口 `HT` / `CK`

## 8. 已知限制

| 限制 | 说明 |
|---|---|
| **笛子缺气声** | 谐波模型表达不了笛膜蜂鸣（8–20 kHz，占能量 2.8%，SNR≈0）。上板比录音"干净"。真正的正路是「谐波 + LFO + 带通噪声」，二期 |
| 唢呐/笛子单声部 | 同一时刻只能响一个音（单实例共享表缓冲） |
| 谐波引擎 4 声部写死 | `rot[2]`、`k_nz[2]` 等硬编码，`NVOICE=1` 会综合失败；只触发 0 号声部 |
| 最差 slack 薄 | +0.006 ns，改动后必须复查 |
| SD 加载 1.1 MB | 上电到 `ld_done` 约几秒 |

## 9. 构建 / 烧录

```bash
cd /mnt/project/InstruementSound/piano64_3
export TMPDIR=/mnt/project/InstruementSound/.tmp \
       LD_LIBRARY_PATH=/mnt/project/ov-cli/Gowin/IDE/lib \
       QT_QPA_PLATFORM=xcb
/mnt/project/ov-cli/Gowin/IDE/bin/gw_sh build.tcl

# 下到 SRAM（调试用，掉电丢）
openFPGALoader -b tangmega138k --ftdi-serial 2025030317 impl/pnr/piano64.fs

# 固化到 Flash（掉电不丢）
openFPGALoader -b tangmega138k --ftdi-serial 2025030317 -f impl/pnr/piano64.fs
```

**串口**：`/dev/ttyUSB2` @ 115200 8N1（`SIPEED_USB_Debugger_2025030317` 的 if01 通道）。
`/dev/ttyUSB1` 是 Digilent Adept，**不是这块板**。

**镜像**：`python3 tools/make_ddr_image.py` → `/mnt/project/InstruementSound/P64.BIN`
→ 拷到 SD 卡根目录（文件名必须是 8.3 的 `P64.BIN`）。

### 常见故障

| 症状 | 先查 |
|---|---|
| 全部没声 | 串口有没有 `LD … OK=1`；`HT`/`CK` 对不对 |
| 某个音色没声 | 该段的 `base_word` 与 `harm_buf` 的 info 偏移 |
| 排完 SRAM 板子像死了 | `Load SRAM 100%` 但跑的是旧码流 → 加 `-f` 重烧一次 |
| 钢琴音高乱 / 古筝没声 | SD 上是旧镜像（`HT=0x19B1`） |
