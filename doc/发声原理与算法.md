> 平台：Sipeed Tang Mega 138K（Gowin GW5AST-LV138PG484AC1/I0）

## 0. 一句话概括

> **音色就是一张参数表；每个采样点都是 FPGA 现场用 64 个正弦分量累加算出来的 —— 没有预录任何 PCM。**

## 2. 时间尺度（关键数字）

```
① 晶振 / PLL
   50 MHz  →  1 拍 = 20 ns

② I2S 位时钟 BCK
   50 MHz ÷ 16  =  3.125 MHz
   1 个 BCK 周期 = 16 拍 = 320 ns

③ 帧时钟 LRCK（= 采样率 fs）
   3.125 MHz ÷ 64  =  48828.125 Hz
   1 帧 = 64 个 BCK = 1024 拍 = 20.48 µs   ← 1 个立体声样点
```

### 为什么必须是 1024

```
     I2S 侧：  DIV × SLOTS  =  1024
                16  ×  64
     ───────────────────────────────── 必须严格相等
     引擎侧：  NPART × 流水线深度 = 64 × 16
```

- I2S 每 1024 拍要一个新样点
- 引擎每 1024 拍才算出新样点
- 不等 → 样点重复读或丢 → **音高 / 节奏全错**

### 为什么不是 48000 Hz

```
50 000 000 ÷ 48000 = 1041.67   ← 非整数，做不到
50 000 000 ÷ 1024  = 48828.125 ← 整数 ✓
```

48828.125 比 48 kHz 高 **0.36%（6 音分）**，人耳分辨率约 10 音分 → 听不出来。

> **注意**：参数表里的相位增量是按 `fs = 48828.125` 算死的。改 `DIV`/`SLOTS` 会整体跑调（1% 偏差 ≈ 17 音分）。

## 3. 音色的数学模型

### 3.1 为什么用加法合成

傅里叶：**任何周期波形 = 若干个正弦波叠加**

```
f(t) = A₁sin(2πf₀t) + A₂sin(4πf₀t) + A₃sin(6πf₀t) + …
        └─基频─┘       └─2次谐波─┘      └─3次谐波─┘
```

不同音色的区别只在**这些系数**：

| 音色 | 泛音结构 | 听感 |
|---|---|---|
| 正弦波 | 只有基频 | 纯净、单薄、"电子音" |
| 方波 | 只有奇次谐波，幅度 1/n | 空洞、像单簧管 |
| 锯齿波 | 所有谐波，幅度 1/n | 明亮、像弦乐 |
| **钢琴** | 谐波丰富、高次快速衰减、带不谐和性 | 温暖、有击弦感 |
| **古筝** | 低次强、有明显起音扫频 | 清脆、有"刮"的感觉 |

### 3.2 真实钢琴的三个特征

1. **不谐和性（inharmonicity）**
   弦有刚度，泛音不是严格整数倍：`f_k = k·f₀·√(1+B·k²)`，略偏高。
   → 听起来"厚"，而不是电子琴的"薄"。

2. **不同泛音衰减速度不同**
   高次泛音 τ 短（衰减快）→ 听感是"叮"一下然后变柔和。

3. **击弦瞬间的宽频谱**
   所有泛音同时起振、相位对齐 → 波形起始处有尖峰 → 这就是"击弦感"。

### 3.3 我们的模型

```
s(t) = Σ  aₖ · e^(−t/τₖ) · cos(2πfₖt + φₖ)      k = 1..64
```

每个音色 = 一张表，每行存一个分量的四个数：

| 参数 | 含义 | 存储位置 | 位宽 |
|---|---|---|---|
| `inc` | 相位增量 = fₖ/fs × 2³² | bank0 | 32 |
| `R1` | 衰减系数 = 2³²/(τₖ·fs) | bank1 | 32 |
| `a16` | 初始幅度 aₖ × 65536 | bank2[31:16] | 16 |
| `phi8` | 初始相位 φₖ/2π × 256 | bank2[15:8] | 8 |

**表规模**

| 音色 | 音域 | 分量/音 | 行数 |
|---|---|---|---|
| 钢琴 | MIDI 21~108（88 音） | 64 | 88 × 64 = **5632** |
| 古筝 | MIDI 36~88（53 音） | 64 | 53 × 64 = **3392** |

每行 3 × 32 位 → 钢琴表约 **66 KB**

### 3.4 重要：相位补偿

我们的正弦表 `add_sine.hex` 存的是 **`sin(i)`**，但模型用的是 **`cos`**。

```
cos(θ) = sin(θ + π/2)
```

所以表的 `phi8` 必须存 `(φ − π/2)/2π × 256`，不能直接存 `φ`。

> **踩过的坑**：不补偿会差 90°，破坏拟合好的相位抵消关系，逐音峰值散布从 0.6 dB 恶化到 9 dB。

## 4. 单个分量的计算

### 4.1 相位累加器

```verilog
ph <= ph + inc;      // 32 位，自动溢出回绕 = 相位取模 2π
```

相位用 32 位"整圆"表示：`2³²` = 一个完整周期 `2π`

```
inc = f / fs × 2³²
```

**实算**（fs = 48828.125）：

| 音 | 频率 | inc | 十六进制 |
|---|---|---|---|
| C4 | 261.63 Hz | 23,012,831 | `0x015F25DF` |
| A4 | 440.00 Hz | 38,702,809 | `0x024E8ED9` |
| C5 | 523.25 Hz | 46,025,653 | `0x02BE4BB5` |

**验证**：C5 的 inc ≈ 2 × C4 的 inc（高八度 = 频率 ×2）✓

### 4.2 正弦表 + 线性插值

不用真算 `sin()`，查表：

```
相位高 10 位  ph[31:22]  →  正弦表地址（1024 点）
相位次 10 位  ph[21:12]  →  插值系数 frac（10 位）
```

```verilog
s0  = sin_table[addr];                         // 当前点
s1  = sin_table[addr+1];                       // 下一点
ds  = s1 - s0;
sv  = s0 + ((ds × frac) >> 10);                // 线性插值
```

**为什么必须插值**：

| 表 | 不插值 SNR | 插值后 SNR |
|---|---|---|
| 正弦表（1024 点） | 还行 | — |
| **钢琴表（2048 点，24 次谐波同相）** | **47.7 dB** ← 明显杂音 | **91.8 dB** |

提升 **44 dB**。钢琴表在击弦尖峰处表项跳变极大（相邻差 1076 LSB），偏偏就是不插值最吃亏的波形。

### 4.3 包络衰减

钢琴是**击弦**乐器：敲一下，指数衰减，**没有持续段**（AD 包络，无 sustain）。

```verilog
env_new = env − (env >> 8) × R / 2^24
```

化简：

```
env_new ≈ env × (1 − R / 2³²)
```

每秒乘 fs 次 → 时间常数：

```
τ = 2³² / (R × fs)
```

**实算**：

| 目标 τ | R 值 | 需要位数 |
|---|---|---|
| 0.3 s | 293,203 | 19 位 |
| 1.0 s | 87,961 | 17 位 |
| 2.0 s | 43,980 | 16 位 |
| 5.0 s | 17,592 | 15 位 |
| **0.5 ms（新表最短板模态）** | **175,921,860** | **28 位** |

> **这就是为什么 R1 要 32 位**：24 位最大只有 16,777,215，τ 下限是 5.24 ms，表里 12~16% 的模态会溢出。

### 4.4 制音器（release）

松开键时，真实钢琴的毛毡压住弦 → 声音快速消失。

```verilog
R_eff = gate ? R1 : R_REL;      // R_REL 对应 τ = 0.30 s
```

直接砍断会听到"咔"的爆音，所以必须有一段快速衰减。

## 5. 64 个分量怎么在一个乘法器上算完

### 5.1 为什么复用

64 个分量并行需要 64 个乘法器；4 声部就是 256 个，远超 DSP 数量（298 个，还要留给其他逻辑）。

**时间复用**：一个样点 1024 拍，轮流算。

### 5.2 计数器划分

```verilog
wire [5:0] p = cnt[9:4];   // 0~63  第几个分量
wire [3:0] s = cnt[3:0];   // 0~15  第几级
```

```
拍号:  0    1    2  ...  15   16   17  ...  31   32  ...  1023
分量:  p0   p0   p0      p0  p1   p1       p1   p2        p63
级:    s0   s1   s2 ...  s15  s0   s1  ...  s15  s0  ...  s15
       └── p0 走完 16 级 ──┘ └── p1 ─────┘
```

**每一拍做一件事**：处理「第 p 个分量的第 s 级」。

### 5.3 16 级流水线

| 级 | 动作 | 用到的资源 |
|---|---|---|
| s=0 | 用地址 p 读参数表 + 读状态 RAM（相位/包络） | BSRAM |
| s=1 | `ph_next = ph + inc` | 加法器 |
| s=2 | 用 `ph_next[31:22]` 查正弦表 | BSRAM |
| s=3 | 再读一个点（插值准备） | — |
| s=4 | `ds = s1 − s0`，`frac = ph_next[21:12]` | 减法器 |
| s=5 | `itp = ds × frac` | **乘法器** |
| s=6 | `sv = s0 + (itp >> 10)` ← 波形值 | 加法器 |
| s=7~9 | 幅度混合 → `amp` | — |
| s=10~12 | `pr = sv × amp` ← 波形 × 包络 | **乘法器** |
| s=13 | `acc += pr` 累加 + 更新包络 | **乘法器 + 加法** |
| s=14 | 计算下一拍的包络值 | 加法器 |
| s=15 | 组装数据写回状态 RAM | — |

**一条流水线上同时有 16 个不同分量的数据在飞。**

### 5.4 硬约束（时序违例的根源）

```
NPART × 流水线深度 = 1024
```

| NPART | 流水线深度 | 每级工作量 | 时序 |
|---|---|---|---|
| **32** | 32 | 0.5× | 宽松（约 25 条违例）|
| **64（现在）** | 16 | 1.0× | 紧张（约 48 条违例）|

64 分量时每级必须做完：ROM 读出 + 24×32 乘法 + 56 位加法 ≈ 23 ns > 20 ns 预算。

> **这些违例不影响听感**：路径都在包络通路上，每 1024 拍才更新一次，偶尔错一次是某个样点幅度千分之一的偏差，被音乐掩蔽掉。

## 6. 复音与混音

### 6.1 复音分配

```
按键按下 → 有空闲声部？ → 用空闲的（取 index 最小）
                      └→ 没有？ → 抢最老的（轮转指针 rr 指向的那个），rr++
```

`rr` 只在**抢声**时才推进（有空闲时推它没意义，还会打乱顺序）。

### 6.2 混音

```
声部0 ─┐
声部1 ─┤
声部2 ─┼─► 加法器 ─► 软限幅 ─► 增益 ─► I2S
声部3 ─┘
```

### 6.3 电平预算（重要）

```
单音峰值 1951
× 4 增益 → 7804 = −12.5 dBFS

4 音叠加 → 31216 = −0.4 dBFS  ← 刚好不削顶
```

| 同时响 | 峰值 | 电平 |
|---|---|---|
| 1 音 | 7804 | −12.5 dBFS |
| 2 音 | 15608 | −6.4 dBFS |
| 3 音 | 23412 | −2.9 dBFS |
| 4 音 | 31216 | −0.4 dBFS |

> **踩过的坑**：原来增益 ×8，4 音叠加 = 62432 = 满刻度的 **190%** → 硬削波 → 刺耳噪音。改成 ×4 解决。

### 6.4 软限幅器

```verilog
if (ax <= KNEE)  mag = ax;
else             mag = KNEE + ((ax − KNEE)² >> 16);
```

超过折点后**平方压缩**，把 1.5 倍的过载平滑压回来。

**为什么不用硬削**：16 位溢出会**符号翻转**（+32767 +1 → −32768）→ 爆音。

## 7. I2S 协议

### 7.1 三根线

| 线 | 全称 | 作用 |
|---|---|---|
| **BCK** | Bit Clock | 每一位的节拍 |
| **LRCK** | Left/Right Clock（= WS） | 标识当前是左声道还是右声道 |
| **DIN** | Data In | 数据，MSB 先出 |

### 7.2 频率关系

```
BCK  = 50 MHz ÷ 16      = 3.125 MHz      （1 BCK = 16 拍 = 320 ns）
LRCK = 3.125 MHz ÷ 64   = 48828.125 Hz   （1 帧 = 64 BCK = 1024 拍）
```

### 7.3 一帧结构

```
LRCK  ‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾\________________/‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾\______
       └──── 左声道 32 BCK ────┘└──── 右声道 32 BCK ───┘

DIN        D15 D14 D13 … D1 D0  0  0  0 …  0  ┃ D15 D14 …
           └─ 16 位数据 ──────────┘└ 16 位补零 ┘
           左对齐
```

**关键点**

- **MSB 先出**
- **数据在 BCK 下降沿更新**，DAC 在上升沿采样 → 留半拍建立时间
- **必须单一时钟域**：全部跑主时钟，用一个计数器派生 BCK / LRCK / 位索引

> **踩过的坑**：用 fabric 分频出来的时钟去驱动逻辑，工具会编一个频率，形成未约束的跨时钟域 → 症状是**音准慢慢跑偏**，极难排查。

### 7.4 PCM5102A vs 板载 PT8211

| | 左声道 | 右声道 | 数据更新沿 |
|---|---|---|---|
| **PCM5102A**（外置） | LRCK **低** | LRCK **高** | BCK 下降沿 |
| **PT8211**（板载） | WS **高** | WS **低** | BCK 下降沿 |

**两者发送器不能互换**，写反就是左右声道对调（单声道测试听不出来）。

## 8. DAC（PCM5102A）

### 8.1 内部处理链

```
I2S 数字流
   ↓
数字插值滤波器（过采样 8×）
   ↓
ΔΣ 调制器（1 bit，采样率 6.144 MHz）
   ↓
开关电容低通（模拟）
   ↓
模拟输出 ≈ 2.1 Vrms
```

**ΔΣ 调制的核心**：用 1 位高速开关 + 反馈，把量化噪声"推"到高频，再用模拟滤波器滤掉 → 等效 24 位精度。

### 8.2 板上关键引脚（接错就不出声）

| 引脚 | 必须接 | 原因 |
|---|---|---|
| **XSMT** | **3.3 V** | 软静音，不接就一直静音 ✗ |
| **FMT** | GND | 选 Philips I2S 格式 |
| **SCK** | GND | 用内部 PLL，只要 3 根线 |
| **FLT / DEMP** | GND | 关掉数字滤波 / 去加重 |
| VIN | 3.3 V | 供电 |
| OUTL / OUTR | 耳机 / 功放 | 2.1 Vrms 线路电平 |

### 8.3 模拟输出之后

```
DAC ──► RC/LC 低通（滤掉 6.144 MHz 的 ΔΣ 残留）──► 功放 ──► 耳机
```

ΔΣ 的输出是高频方波序列，**平均值**才是音频信号，低通滤波器取平均值。

## 9. 完整数据通路：按一下 do

### T=0 按下按键

```
key_in[0] 拉低
→ key_scan：内部取反成高有效，8 ms 消隐窗确认
→ key_press[0] = 1（一个时钟宽）
→ note_alloc：分配声部 0，v_note[0] = 60 (C4)，v_trig[0] = 1
```

> **按键极性坑**：引脚有片内上拉，**松开=高、按下=低**。必须 `wire raw = ~key_in[g]` 先统一成高有效，否则边沿出现在"松手"那一刻 —— 现象是"碰地不响、离开才响"。

### 引擎装载（下一拍）

```
查参数表第 60 音（地址 = (60 − 21) × 64 = 2496 起，共 64 行）
对每个分量 k：
  ph[k]  = phi8[k] << 24        （初始相位）
  env[k] = a16[k] << 16         （初始幅度）
```

### 每个样点（20.48 µs）

```
对 64 个分量，每拍处理一个 (p, s)：
  s=1:    ph += inc                相位前进
  s=2~6:  正弦表插值 → sv          波形值
  s=13:   acc += sv × env          乘包络并累加
          env -= env × R / 2³²     包络衰减
```

### 混音输出

```
4 个声部相加 → 软限幅 → ×4 → 16 位样点
```

### I2S 发送（1024 拍）

```
64 个 BCK × 每 BCK 16 拍
每个 BCK 送 1 位
32 BCK 送左声道 16 位 + 16 位补零
32 BCK 送右声道
```

### DAC → 耳机

```
16 位数字 → ΔΣ 调制 → 模拟电压 → 低通 → 功放 → 空气振动
```

### 松手

```
key_release → v_gate[0] = 0
→ R_eff 从 R1 切到 R_REL（τ = 0.3 s）
→ 包络快速衰减到 0 → 静音
```

## 10. 资源与时序

### 10.1 资源占用（`piano64`，64 分量 / 4 声部 / 1 音色）

| 项 | 用量 | 占比 |
|---|---|---|
| Logic | 2785 / 138240 | 3% |
| Register | 1866 / 139095 | 2% |
| BSRAM | — | 56% |
| DSP | 14 / 298 | 5% |

### 10.2 时序

Fmax ≈ **43 MHz**（最长路径 23 ns），需求 50 MHz（20 ns）→ 差 15%。

违例全部在 `add_voice` 的包络通路上。

**四象限账**：

| 环节 | 延迟 |
|---|---|
| 参数 ROM 读出（BSRAM） | ~2 ns |
| R1 多路选择 | ~1 ns |
| 24 × 32 乘法器 | ~3 ns |
| 56 位加法 + 舍入 | ~2 ns |
| 各级走线（BSRAM 占 56% 路由，单元摊得远） | ~10 ns |
| **合计** | **~23 ns** |

### 10.3 想改善时序的路径

| 方案 | 效果 | 代价 |
|---|---|---|
| **NPART 64 → 32** | 流水线 16→32 级，每级工作量减半 | 音色变薄 |
| R1 32 位 → 24 位 | 乘法器 24×32 → 24×24 | 快速衰减模态（τ<1ms）表示不了 |
| 多引擎并行 | 每级工作量降低 | BSRAM 读端口不够（最多 2 引擎）|

**结论**：违例不影响听感（包络每 1024 拍才更新），可以不动。

## 11. 已验证的坑（全部踩过）

### 11.1 音频链

| # | 坑 | 现象 | 修法 |
|---|---|---|---|
| 1 | 包络用 16 位 | `env -= env>>13` 在 env<8192 后退化成线性，0.4 s 就断 | 改 24 位包络 |
| 2 | 没有制音器释放段 | 换音时直接砍 → "咔" | 加 REL_N 线性/指数释放 |
| 3 | 波表不插值 | 钢琴表 SNR 只有 47.7 dB（杂音） | 32 位配对表 + 线性插值 → 91.8 dB |
| 4 | 定点乘法链漏一级 `>>>15` | 输出爆 16 位 → 静默翻转成噪声 | 每级 16×16 各自归一化 |
| 5 | 增益过大削波 | 4 音叠加 190% → 刺耳 | 增益 ×8 → ×4 |
| 6 | 相位没补偿（cos vs sin） | 逐音峰值散布 9 dB | `phi8 = (φ−π/2)/2π×256` |
| 7 | 频率字锁存错拍 | 所有键弹同一个音 | 在按键那一拍锁存 |

### 11.2 时序 / 结构

| # | 坑 | 现象 | 修法 |
|---|---|---|---|
| 1 | 时间复用初始化没对齐输出周期开头 | 早到的分量多走一个样点相位，幅度小 8% | 等 `cnt==0` 再装载 |
| 2 | 样点不在帧边界更新 | 每帧一响 | 用 `sample_tick` 重新锁存 |
| 3 | 流水线里地址和系数错开一拍 | THD+N 掉到 −63 dB | 所有相关量同一拍装载 |
| 4 | `dur = UNIT × cur_beat` 组合乘法 | 23.6 ns 路径 | 打一拍 |

### 11.3 Verilog 语言坑

```verilog
// ❌ 循环里用非阻塞赋值求和 → 只有最后一次生效
always @(posedge clk) begin mix <= 0; for(...) mix <= mix + v[i]; end
// ✅ 组合块里用阻塞赋值
always @(*) begin sum = 0; for(...) sum = sum + v[i]; end
always @(posedge clk) mix <= sum;

// ❌ 有符号 × 无符号 → 整个乘法按无符号算
wt <= dif * w8;
// ✅ 给无符号操作数套 $signed 并补一位 0
wt <= dif * $signed({1'b0, w8});

// ❌ 对 integer parameter 做位选（NOTE_LO[6:0]）→ 非法
// ✅ 先 localparam [6:0] NLO = NOTE_LO; 再 NLO

// ❌ 状态机加了新状态但输出判据没改
dout <= (state == 1'b1) && ...   // state 已扩成 2 位，S_SEND = 2'd2 → 永远不成立
// ✅ 用符号名
dout <= (state != S_RESET) && ...
```

## 12. 一句话总结每个环节

| 环节 | 一句话 |
|---|---|
| **采样** | 每 20.48 µs 记一个数，够密才不失真 |
| **音色** | 一张 88 音 × 64 分量的参数表（幅度 / 衰减 / 频率 / 相位）|
| **分量合成** | 相位累加器 + 正弦表插值 + 指数包络，64 个分量相加 |
| **时间复用** | 1024 拍轮流算 64 分量 × 16 级流水线，一个乘法器干 64 份活 |
| **复音** | 4 个独立引擎并行，全忙时抢最老的声部 |
| **混音** | 4 路求和 + 软限幅，增益 ×4 保证 4 音叠加不削顶 |
| **I2S** | 3 根线、MSB 先出、每帧 1024 拍送左右各 16 位 |
| **DAC** | ΔΣ 调制 + 模拟低通，把数字还原成电压 |
| **整体** | 数学公式 → 硬件时序 → 模拟电压 → 空气振动 |

## 13. 赛题合规性说明（答辩用）

| 赛题要求 | 我们的实现 |
|---|---|
| 纯硬件实时合成，延迟 ≤ 10 ms | 按键到 I2S 输出 **82 µs**（IMMEDIATE 消抖）|
| 复音 ≥ 4 | **4 声部**，全忙时抢声 |
| 单音加法分量 ≥ 32 路（拓展 1）| **每音 64 路** |
| 严禁预录 PCM / 整段录音触发 | **只存谐波参数表**（频率 / 幅度 / 衰减常数 / 相位），每个采样点都是 FPGA 实时算出 |
| ≥ 2 音色切换（拓展 2）| 钢琴 + 古筝，双引擎并行，切换只切音频输出 |

> "我们存的是**参数**，不是波形。表里 5632 行 × 3 个数字，每行描述一个正弦分量的频率、幅度、衰减和相位。6400 万个采样点没有一个是预存的 —— 全是 FPGA 用 64 个振荡器现场累加出来的。"
