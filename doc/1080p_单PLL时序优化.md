# 单PLL1080p时序优化（2026-11-04）

单PLL的1920×1080约30.303Hz和60.606Hz彩条均已由用户确认正常显示。此前级联PLL方案未正常显示，仍保留为独立诊断历史。

第一轮150MHz完整工程的全局时序为41个setup违例、hold为0，最差-0.332ns，未上板。失败固件、输入指纹和报告保留在work/hdmi_single_full/failed150。该轮68条PASS回归、13张原厂显存模型截图对照，以及翻页计数器全部进位/暂停/恢复检查均通过。

第二轮按实际路径修改：SD空闲扇区递增与边界比较分成独立状态；描述符数据本来无复位，改为由状态/有效握手直接捕获，复位仍清除FSM与所有输出写使能，从而避开复位的长扇出；1080p串行器前增加无条件像素寄存器，隔开编码逻辑与IO线路。

描述符响应中途复位/重新开始，随后全部53个真实音符、8类表、507115个元素均检查通过。实际生产PLL与新串行器的独立差分引脚接收检查也已通过，确认启动和外部复位后的完整行、RGB、同步与通道对齐。新增寄存器只增加共同的视频延迟，720p物理输出分支不采用该改动。

第二轮完整构建已完成：全局setup/hold为0/0，最小报告setup +0.005ns，BSRAM 313/340。68条PASS功能回归、18个端到端音频延迟场景全部通过，最慢2.794ms。完整150MHz固件已成功临时加载SRAM，等待用户确认三页和声音；尚未宣称整机实物验收通过。实验只在candidate/1080p60-after-keys-20261104分支，main和Flash保持已验收低延迟720p。
